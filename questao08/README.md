# 🎓 Cadastro Acadêmico – Registro de Estudantes

![React Native](https://img.shields.io/badge/React_Native-0.81.5-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)

Aplicativo mobile desenvolvido em **React Native** com **Expo** para gerenciar o cadastro e a listagem de estudantes de uma instituição de ensino[cite: 8].

---

## 📋 Sobre o Projeto

O aplicativo funciona como um mini sistema de gestão acadêmica, permitindo cadastrar novos alunos com validação de dados e exclusão dinâmica de registros[cite: 8].

### ✨ Funcionalidades

- **Formulário Completo:** Campos dedicados para Nome, Matrícula, E-mail e Curso[cite: 8].
- **Validação de Duplicidade:** Impede o cadastro de matrículas duplicadas no sistema[cite: 8].
- **Listagem Dinâmica e Exclusão:** Exibe a contagem total de estudantes registrados em formato de cards individuais com opção de remoção[cite: 8].
- **Interface Responsiva:** Otimizada com `ScrollView` e `KeyboardAvoidingView` para navegação fluida em dispositivos móveis[cite: 8].

---
